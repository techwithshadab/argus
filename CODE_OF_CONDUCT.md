# Code Of Conduct

## The Short Version

Be decent. Argue about the work, not the person doing it.

## Our Standards

Things that make this project better: clear technical disagreement, saying "I was wrong"
early, asking the obvious question, reviewing someone's code as carefully as you would
want yours reviewed, and assuming the other person had a reason.

Things that are not acceptable: harassment of any kind, personal or political attacks,
publishing someone's private information, sexualised language or imagery, and sustained
disruption of discussions.

This applies in issues, pull requests, commit messages and anywhere else the project is
represented.

## Scope And Enforcement

The maintainer may edit or remove contributions that do not meet this standard, and may
block accounts, with an explanation where that is possible.

To report a problem, use GitHub's private vulnerability reporting on this repository,
which reaches the maintainer privately, or contact the maintainer through their GitHub
profile. Reports are handled confidentially. The maintainer is a participant here too, so
if the problem is with the maintainer's own conduct, GitHub's own reporting channels are
the right route.
