# Argus Gap Audit

Date: 8 September 2026. Scope: the whole repository (agents and tool plane, platform API and jobs,
infrastructure and operations, watch floor UI and documentation) plus the live deployment. Method:
four independent code reviews with file and line references, a dependency scan, container checks
and live evidence from the running stack. Every finding names the file, the failure and a fix.
Severity is by consequence if left alone: high means data, security or a wrong decision on the
floor; medium means reliability, cost or a misleading result; low means polish.

**Status 9 September 2026.** Every finding in this audit is now fixed or explicitly narrowed, each with a unit test: 434 tests, and `cdk synth` is a real gate with seventeen template assertions. Four architecture decision records were written (ADR-0019 to ADR-0022). Three items are deliberately left open and named in their rows: exercising the restore end to end, a certificate expiry alarm whose metric may not publish for an imported certificate, and bulk review in the watch floor. Phases 0 and 1 are complete. Phase 1 closed I3, I4, I7, I12, I13, I14, I20, P5, P12, U3 and U4, each with a unit test: the suite is 312 tests and `cdk synth` is now a real CI gate with nine template assertions. Phase 0 is complete: P1, P2, P3, P4, P6, A1, A2, A3, I1, U1, U2, D1 and D2 are fixed, each with a unit test, plus parts of A8 and I2 that fell out of the same work. Two architecture decision records were written (ADR-0019, ADR-0020). The suite is 250 tests; lint, format, compose and synth all pass. Phases 1 and 2 below are untouched.

## Live Evidence From The Deployment

- `argus-degraded-branches` was in ALARM at audit time: at least three Investigator branches degraded within an hour on live traffic. Combined with finding A3 below (a degraded branch does not cap the report's confidence), this is the path to a confident wrong report.
- 131 open alerts and 18 tasking proposals awaiting decision after one day; two AISStream reconnects; no ingest errors.
- All ten container images run as root (no `USER` in any Dockerfile).
- `pip-audit`: no known vulnerabilities in the API, MCP server and ingest pin sets; the two agent pin sets did not resolve offline and are unchecked.
- Cost Explorer returned zero for the last three days, so the cost table in the blog remains an estimate; billing data for this account lags or is not enabled for the API.
- The eval gate has never run against AWS (root cannot assume `argus-operator`), so the four `argus-eval-*` alarms sit in INSUFFICIENT_DATA and the Grafana gate tiles read "No data".
- Orphan `vpc-05e92ece7c6ddf38f` from the previous stack is still pinned by AgentCore-managed network interfaces.
- The repository carries no licence; the Agents for Humans hackathon (deadline 14 Sep) requires MIT or Apache.
